# Sega System 16B — integrato

File release: `system16jsd.html`

Sorgente integrata: `Sega_Arcade_JSD_unified_alpha17_system16_audio.html`.

La build contiene il core nativo System 16B con Motorola 68000, mapper/I/O, video 315-5197/315-5196 e audio Z80/YM2151/uPD7759. L’HTML originale resta standalone; l’Hub aggiunge solamente un ricevitore opzionale `postMessage` per aprire automaticamente il set ZIP selezionato.

Il launcher tratta System 16 come sistema distinto dal Mega Drive, anche se l’HTML unified conserva internamente i propri percorsi Mega-Tech/Mega Play e compatibilità Sega.
