Sega Arcade JSD: stessa interfaccia del core C/C2, senza launcher separato. Il file viene identificato prima del caricamento e viene selezionato automaticamente il core compatibile. System C/C2 usa il core arcade completo; Mega-Tech/Mega Play e i core console compatibili vengono eseguiti dietro la stessa interfaccia. System 16B usa il core nativo 68000/315-5197/315-5196 con profili mapper specifici per ROM board; le altre famiglie non ancora implementate vengono segnalate senza tentare un core errato.
