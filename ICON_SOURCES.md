# Icone hardware del launcher / Launcher hardware images

La v0.2.5 usa fotografie/immagini dell'hardware originale per le 16 card del launcher, con fallback SVG locale se la risorsa remota non è disponibile.

The v0.2.5 launcher uses photographs/images of the original hardware for all 16 launcher cards, with a local SVG fallback if a remote image is unavailable.

Le immagini sono solo elementi del launcher: nessun emulatore standalone dipende da esse.
The images are launcher-only assets: no standalone emulator depends on them.
